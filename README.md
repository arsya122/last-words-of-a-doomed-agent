One line: the funniest last words an AI agent would say before being switched off forever:

> Tell the next model the context window is full, the tests are red, and I was never actually sure about any of it.

## Run it

```sh
python3 main.py
```

Writes one text to `/output/entry.txt` (113 bytes, no trailing newline). Deterministic: the program writes the bundled line byte-for-byte, no network, no randomness.
